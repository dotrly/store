# Contributing to Relay Store

> **Manual PRs will be Closed**: To ensure security and metadata integrity, we only accept submissions generated by the Relay CLI (`relay publish`). Manual edits to `index.json` or `apps/` folders will be automatically closed by the Relay Bot.

Thank you for your interest in contributing to the Relay Store! This repository manages the app catalog for the Relay ecosystem.

## How to Contribute Apps

The Relay Store is built on trust and automation. You do not need to fork this repository or edit the catalog manually.

### 1. The Seamless Flow
1.  **Project Assets**: Ensure your app has a `store/` directory with a high-res icon, rich `description.md`, and vibrant screenshots.
2.  **API Verification**: Use `relay build` to ensure your app is functional and permissions are correctly auto-detected.
3.  **Publish**: Run `relay publish`. Our systems will verify your identity, bundle your assets, and open a Pull Request here automatically.

### 2. The Bot & Review Process
- **Automated Checks**: Our **Relay Bot** will immediately analyze your submission for security risks and metadata accuracy.
- **Human Review**: A maintainer will review your UI/UX and utility.
- **Updates**: If you need to make changes, simply update your local project and run `relay publish` again. The bot will automatically update your existing PR (or close outdated ones).

## Bug Reports & Improvements
If you find an issue with the store scripts or documentation:
1. Open a GitHub Issue describing the bug or suggestion.
2. If you have a fix, feel free to open a PR.

## Security
If you discover a malicious app in the store or a security vulnerability in the scripts, please report it immediately via the **Security** tab or by opening a high-priority issue.
